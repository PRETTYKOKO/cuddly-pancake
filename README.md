 Personal Meal Planner

A simple web application that generates a personalized meal plan based on user information.

 Features
 
 Enter personal details:

  * Name
  * Age
  * Weight
  * Gender
  * Genotype
  * Lifestyle habits (smoking, drinking)

 Conditional questions for females:

  * Pregnancy status
  * Menstruation status

 Generates a meal plan based on the information provided.

 Technologies Used

* HTML
* CSS
* JavaScript

 How to Use

1. Open the application.
2. Fill in the required details.
3. Click **Generate Meal Plan**.
4. View your personalized meal recommendations.

 Future Improvements
